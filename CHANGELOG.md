# Changelog

## 1.5.0 — 2026-10-12

* Adopt the public name Photothermal Workbench (PTW).
* Supply a portable Windows x64 GUI and command-line executable with a shared runtime.
* Add homogeneous, layered and absorption-enhanced procedural phantom inputs.
* Load a phantom by default; no external mouse atlas or smooth mesh is needed to launch.
* Import the documented MCX Digimouse JSON and derive display surfaces from its labels.
* Preserve input physical scale and retain material settings in portable project files.
* Fit model-derived surfaces to the viewport and colour their outer material labels.
* Clarify that an active solver cannot be interrupted through the Stop menu.
* Add instructions, mouse-source guidance and runtime license notices.

Existing interactive numerical kernels are retained. This release does not distribute manuscript reproduction results or establish equivalence with separate paper-specific batch solvers.
