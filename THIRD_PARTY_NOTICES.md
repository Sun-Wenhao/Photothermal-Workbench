# Third-party notices

The executable release bundles a Python runtime and libraries. The original licenses and bundled third-party notices are included in its `licenses/` folder and, where provided upstream, runtime package data. The PTW license does not replace them. Some dependencies supply support modules used by other bundled libraries.
